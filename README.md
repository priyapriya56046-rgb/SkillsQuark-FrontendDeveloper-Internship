- Home, About, Skills, Projects, and Contact sections
- Dark and light mode toggle

## 🌦️ Task 02 — Weather Dashboard

An interactive weather application that allows users to search for a city and view its current weather information.

**Key Features**
- Search weather by city name
- Display current temperature and weather conditions
- Show humidity and wind speed
- Retrieve weather information through an API
- Handle invalid city searches

**Technologies:** HTML5 · CSS3 · JavaScript · Open-Meteo API
